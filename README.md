# ai-app-valuation

**30 分钟尽调前估值框架**：AI 应用公司（卖智能/功能/结果的公司——不是模型实验室、不是硬件）的四步评分卡：定档 → 生死关 → 质量分 → 估值区间。

> 由公众号 X 系列文章作者维护。框架源自一级市场亲历 + 上市公司财报实证，已用于 14+ 真实案例。

---

## 这是什么

一个**可执行的估值方法论 + 确定性计算引擎**，回答三个问题：
1. 这家 AI 应用公司卖的是什么？（定档：项目/订阅/转售/自研智能）
2. 它会不会死？（五死因生死关）
3. 它值多少？（档位 × 增速矩阵 + 质量分修正）

**核心主张**：AI 应用估值的关键不是模型多强，而是**收入单位**——你在收「项目的钱」还是「智慧的钱」？中报里一行收入确认方式（时间点 vs 随时间）比任何叙事都诚实。

## 快速开始

```bash
# 1. 拷贝 skill 到你的 agent skills 目录（Claude Code / Hermes 等）
# 2. 运行估值引擎（确定性计算）
python scripts/estimate.py --arr 1000 --tier tier3 --growth 0.8 --quality 8.5
# → 倍数区间 + 估值区间（如 $15.7-17.5B）

# 3. 写完报告跑校验（来源真实性/估值链/置信度三查）
python scripts/validate.py your_report.md
```

## 四步框架

1. **Step 1 · 定档**（卖的是什么）——第零档·项目制 / 一档·订阅 / 二档·转售智能 / 三档·自研智能
   - 上市公司的分水岭证据：财报「收入确认」附注——**按时间点确认 >70% = 项目制**（海致 97.4% 实证）
2. **Step 2 · 生死关**（会不会死）——五死因：概念热 / 无存量预算 / 单点功能 / 价格战 / 责任链
3. **Step 3 · 质量分**（0-10）——七指标：智慧自有率 / 单位成本趋势 / IER / 数据回流 / 归因资产化 / 护城河 / 爬升检验
4. **Step 4 · 估值**——矩阵（档位 × 增速）+ 插值 + 修正系数，由 `estimate.py` 确定性输出

## 数据依赖说明（重要）

**框架本身是自洽的**——你可以手填数据完成全流程（BP/招股书 + 自己的判断）。

**但实操中推荐接入数据/信息源**（这是估值锚点的质量来源）：

| 数据需求 | 推荐来源 | 类型 | 必要性 |
|---|---|---|---|
| 上市公司行情/市值/TTM 收入 | **Wind MCP**（`stock_data`）| 行情 API | 高——锚点校准唯一 S 级源 |
| 港股公告/招股书 PDF | HKEX News 披露易（免费） | 官方披露 | 高——定档证据（收入确认附注） |
| 美股财报 (10-K/10-Q) | SEC EDGAR（免费） | 官方披露 | 高 |
| 一级市场融资/ARR 新闻 | **Exa / Tavily 搜索** | 新闻检索 | 中——一级市场无财报，靠多源交叉 |
| 券商研报 | 东方财富/发现报告等公开转载 | 二手 | 中（B 级，不直接作锚） |

**数据纪律（为什么锚点必须 Wind）**：
> 锚点校准一律 **Wind S 级 TTM PS**（市值 ÷ TTM 收入，统一口径）。Web 二手数据站（financecharts/companiesmarketcap/TIKR）各自用 EV/forward/NTM 口径，数值差异可达 20-50%——2026-09 实证：Atlassian web 报 5.9x 实为 Wind 7.2x、Datadog web 报 11.4x 实为 21.9x。**Web 只作方向参考不作校准数值。**

### 在你的 agent 环境里接数据源

本框架以 **MCP（Model Context Protocol）工具**形式消费数据。常见配置：

- **Wind MCP**（付费，金融数据）→ 挂载后估值脚本可拉实时锚点
- **Exa / Tavily MCP**（搜索）→ 一级市场尽调
- 没有 MCP 时：手动把 Wind/港交所/EDGAR 数据贴进报告即可（validate.py 会校验来源等级）

> 没有 Wind 也能用框架——降级为「招股书 + 公开新闻 + 手动填数」，锚点查 `references/comps-source.md`（附最新可比公司 PS 表）。

## 防幻觉设计（为什么结果可信）

- **来源分级 S/A/B/C/D + [N] 索引**：每个数字可回溯到原始来源
- **上市公司必须先读财报原文**（S 级），再券商、再新闻——**「自称模式 ≠ 会计模式」**（范式「Agentic RaaS」/迅策「Token 第一股」/海致「AI 公司」全是没读原文被自称带偏的教训）
- **来源 URL 铁律**：每条来源必须真实可点开——招股书/中报/研报给链接，禁「—」占位
- **validate.py 三查**：R 段来源真实性（URL 可访问 + S 级白名单）/ C 段估值链一致 / D 段报告完整（附件零必含）
- **锚点纪律**：次新股未充分解禁不可作锚（PS 是流通盘稀缺溢价非均衡价）
