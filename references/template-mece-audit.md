# 报告模板 MECE 审计（v1.15.0 起——框架校准两轮要求「模板不 MECE」后沉淀）

> 触发：校准要求「再看看模板里还有哪些不 MECE」「XX 和 XX 是不是重复了」。MECE 是对估值模板的硬性质量要求——同证据跨章评两遍、定义/推导链在正文与附件重复 = 会被当场指出。

## 审计方法：五类重叠模式（每轮模板审计逐类排查）

审模板时不是「通读找感觉」，而是按以下**重叠模式清单**逐章扫：

1. **同证据跨章打分**——同一事实（如数据飞轮/分发渠道）在 A 章定性评估、B 章又打分、C 章护城河再算一层。修法：定性章末尾写「→ 打分依据已进第 X 章相应指标」，打分章 evidence 引用定性章结论，不重复论证。
2. **同名「N 层」语义撞车**——两套同名但定义不同的框架并存（如「能力纵深六层」基座→结果定价 vs 「护城河六层」品牌/数据/规模/网络/切换/独占），读者混淆且中间层证据重叠。修法：改名去歧义或明确分工。
3. **定义列 vs 附件定义表整列重复**——正文表格每行带「定义」列，附件又有完整定义表再说一遍。修法：正文删定义列，定义唯一源放附件，正文留指针。
4. **「清单」跨章本质同一件事**——第一章「未披露清单」与第十章「DD Priority」同源（没披露留存率 → 尽调去问留存率）。修法：合并为一处，另一处一句话映射。
5. **推导链正文 vs 附件表重复**——第七章「矩阵格→插值→修正→估值」与附件一「落位示意」同一推导写两遍，一处改另一处忘改就打架。修法：正文只留「输入+三情景+有效区间」，完整推导链唯一源在附件一。
