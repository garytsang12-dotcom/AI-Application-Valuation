# HKEX 招股书核实工作流（上市公司估值必做）

> 触发：任何港股/A 股上市公司标的，Step 0/Step 1 前必须先读招股书/年报原文。审计财务数据（净资产/流动比率/负债/毛利率/留存率）以招股书为准，媒体转述只做交叉验证。
> 教训：极视角（未读招股书却标 S 级来源 + 把平台聚合误判为自研）、海致（净资产/流动比率明明在招股书审计数据里，标成新浪 B 级）、滴普（留存率在招股书运营数据表里，误标券商）。

## 1. 拿招股书链接

- 搜索 `exa: <公司名> <代码> 招股书 hkexnews` 或直接找港交所披露易
- 标准 URL 形态：`https://www.hkexnews.hk/listedco/listconews/sehk/YYYY/MMDD/YYYYMMDD00XXX_c.pdf`
- 券商/财经站常有镜像（KGI/国泰君安/ccnew），招股书原文通常 500-1000 页

## 2. 下载 + 全文检索

```bash
curl -sL -o prospectus.pdf "<hkexnews URL>" --max-time 60 -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"
```

```python
import pymupdf  # 或 fitz（同名）
doc = pymupdf.open('prospectus.pdf')
# 用繁体关键词搜（简体常搜不到）：

```

## 3. 关键财务数据在招股书的落点（港股本）

| 数据 | 位置 | 海致实证 |
|---|---|---|
| 财务比率（毛利率/流动比率/经调整净利率） | 概要章「主要財務比率」表 | 流动比率 0.3 倍 @ 第 29 页 |
| 流动资产/负债净额、赎回负债 | 财务资料章「流動資產╱（負債）淨額」 | 流动负债净额 15.13 亿 @ 第 406 页 |
| 净资产/权益总额 | 附录一会计师报告「綜合權益變動表」 | 2025-01-01 权益 -13.51 亿 @ 附录一 I-12 |
| 留存率/复购率/CAC/客户数 | 业务章「主要運營數據」表 | 滴普留存 14.6% 在此 |
| 分部收入/毛利率 | 财务资料章分部收入表 | — |

## 4. 标注纪律

- 审计财务数据（净资产/流动比率/负债/毛利/留存率）→ 招股书 [N] **S 级 + 页码**
- 券商研报 → B 级，只补充招股书没有的分析（LTV/CAC 测算、估值对比）
- 财经新闻 → C/B 级，只交叉验证，不能做唯一来源
- 索引表 S 级来源行必须写明读了什么（招股书/年报/中报原文 + 页码；v1.15.0 起不再要求单独的「来源核查清单」段，📖 类符号会被 S6 判硬错）——只有研报/新闻支撑的财务数据 = 违规（R8）

## 5. 中期业绩公告（1H/全年，forward 估值必取，v1.7.1 补充）

当前时点（8 月）估值**必须用 1H26 实绩**（forward 纪律），不能只用上年年报：

- **获取**：exa 搜 `<公司名> <代码> 2026 中期业绩 半年报` → 港交所披露易 PDF（URL 形态 `https://www.hkexnews.hk/listedco/listconews/sehk/2026/MMDD/2026MMDD00XXX_c.pdf`，8 月中下旬发布）+ 格隆汇/证券时报/新浪解读（B 级交叉）
- **⚠️ exa/搜索拿不到公告 PDF 时——用 hkexnews 标题搜索交互页兜底（2026-09-02 海致/迅策实证）**：
  1. 浏览器打开 `https://www1.hkexnews.hk/search/titlesearch.xhtml?lang=zh`
  2. 股份代號/股份名稱 输入框打公司中文名 → 下拉出现候选（如「02706 海致科技集團」）→ 点候选行选中
  3. 日期默认 1999→今天已够（覆盖中报期）→ 点「搜尋」→ 结果列表按发布时间倒序
  4. 目标文件是标题含「中期業績」「截至2026年6月30日止六個月」的公告（类别 `[中期業績]`，629KB 级 PDF）
  5. 拿 PDF 直链：browser_console 执行 `(() => { const links = document.querySelectorAll('a'); for (const a of links) { if (a.textContent.includes('中期業績') && a.textContent.includes('2026年6月30日')) return a.href; } return '未找到'; })()` → 得到 `https://www1.hkexnews.hk/listedco/listconews/sehk/2026/MMDD/2026MMDD00XXX_c.pdf`
  6. curl 下载 + pymupdf 检索（简体搜不到用繁体：收入確認/時間點/隨時間推移）
- **不要浪费时间在 titleSearchServlet.do API 直调**：它对中文公司名/中文标题返回空或无关结果（需要内部 stockId，非公开可查）——直接走浏览器交互页
- **必取字段**：1H 收入/同比、毛利率、归母净利（扭亏?）、**分部收入（每段同比）**、在手订单、销售费用率、研发费用率、算力/资本开支
- **1H26 分部数据是 forward SOTP 的核心输入**（范式实证：API 段 1H26 +860.8% 占比 12.3%，TTM 数据完全看不到——2025 年报里 API 只占 1.1%）
- 媒体解读（格隆汇/新浪）常给「成本/收入剪刀差、毛利趋势、经营杠杆」等深度分析——招股书/公告给数据，媒体给归因，两者交叉

## 6. Wind PS 是滚动 12 个月口径（不是年报口径）

Wind 返回的 `最新市销率PS` 用的是**滚动 12 个月收入（含最新中报）**，不是纯上年年报：
- 范式实证：市值 156.43 亿港元，Wind PS 1.64x（滚动收入 = 2025H2 45.09 亿 + 2026H1 37.65 亿 = 82.7 亿人民币）；若按 2025 年报 71.35 亿算 = 2.0x
- **写报告必须区分三种口径**：①Wind PS(滚动) ②年报口径 PS ③Forward PS（2026E）——框架校准方 v1.7.1 要求双口径展示（TTM + Forward）

## 7. 坑

- 繁体关键词：流動/負債/權益/虧絀/贖回（用繁体搜）
- PDF 可能 15MB+/600+ 页：全文检索比肉眼快
- 港股净利双口径：归母净亏 vs 经调整净利量级可差 10 倍（范式智能 2,630 万 vs 1,784 万）
- 复购率 vs 留存率口径差 2 倍+：复购=历史买过≥2 次；留存=当期活跃（滴普 33.2% vs 14.6%）
- 负资产常由「赎回负债」（可赎回优先股/对赌）推动——上市转股可能回正，判断持续经营风险要看对赌条款，不只看净资产数字
- 1H 分部增速可能大幅偏离年报增速（范式 Agentic：2025 全年 +93% vs 1H26 仅 +4.9%）——**增速必须用 forward/最新半年度，不能用上年年报**
