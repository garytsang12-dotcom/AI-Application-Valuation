# 锚点校准方法论（v1.7.6 · 范式智能 6 轮 + 金蝶 2 轮校准沉淀）

> 用途：给估值矩阵的档位/格子找锚点时，按本方法拉数据、验证、定档。2026-08-31 范式智能+金蝶案例的完整校准过程还原。

## 1. 校准触发信号（团队校准）

| 校准记录 | 深层含义 | 回应套路 |
|---|---|---|
| 「二档纯转售锚点在哪」 | 你给的倍数没有锚支撑 | 查 comps-source.md 对应档位；缺锚 → 拉数据补 |
| 「它的 PS 也是和增速挂钩的吧」 | 锚不能是固定数字，要 f(增速, 毛利, 生态) | 拉同型公司不同增速的对照，画锚带 |
| 「海外看看 token 转售估值到啥水平」 | 只看了国内/一级不够 | 拉海外上市/收购价/一级轮次 |
| 「像不像无问芯穹」 | 类别可能定错了 | 深挖业务本质 → 对照同类公司 → 可能换档/单列 |
| 「自持重资产和租赁调度经济模型区别很大」 | 倍数要按资产轻重分档 | 拆资产结构 → 分别锚定 |
| 「国内有对标吗」 | 海外锚不适用国内 | 拉 A 股/港股同类上市公司 |

## 2. 拉锚点数据的顺序（优先级）

1. **国内上市公司对标**（Wind 批量拉市值/PS/收入/增速）——同一赛道同一市场，最硬
2. **海外上市公司对标**（Wind 拉 .N/.O）——公开市场定价，可验证
3. **收购价反推**（OpenRouter $7.5B÷$140M = 53.6x）——最真实的市场定价，但注意战略收购溢价（标 ⚠️）
4. **一级市场轮次**（融资额/ARR/估值）——单源多标 ⚠️，检查是否「刚融资未验证」
5. **反例**（wrapper 崩塌归零）——锚带的另一端

Wind 批量查询技巧：代码格式 `.HK`/`.SH`/`.SZ`/`.BJ`/`.N`/`.O`/`.L`；一次查 5-8 个代码最稳；美股代码用简称查（「查询美股 Salesforce ServiceNow」比代码稳）。

## 3. 锚带验证套路（范式 §1 档 → 金蝶一档的完整示范）

1. **先列矩阵格子**（档位×增速）
2. **逐格找实证**：
   - g1（<15%）：国内 2.5-5.5x（金蝶 3.55/用友 3.77/泛微 5.55）+ 海外 4.6-5.9x（Adobe 4.6/CRM 4.8/SAP 5.94）→ **3-5x ✅ 实证**
   - g2（15-30%）：Atlassian 7.33x / ServiceNow 10.16x → **6-10x ✅ 实证**
   - g3（30-60%）：高增速 SaaS 多未上市/私有化 → **推断格，标 ⚠️**
   - g4（>60%）：CrowdStrike 41.44x（毛利极高+安全溢价）→ 上沿有支撑
3. **结论只有三种**：✅ 实证 / ⚠️ 推断（无真实锚点，防高估要收窄）/ ❌ 反例（扭曲不可用）
4. **跨市场折价规则**：国内 vs 海外同档位折价 30-50%（流动性+盈利+增速）——中国公司一档 g1 取下沿 3-4x 而非中位

## 4. 类别纠错流程（范式 API 六轮校准实录）

| 轮 | 复核问题 | 校准结果 | 沉淀 |
|---|---|---|---|
| 1 | 用 2026 预测值 | TTM → Forward（2026E consensus） | SKILL.md forward 纪律 |
| 2 | 不要自己预测 | 自测 → 券商 consensus（中金/申万/国泰海通） | consensus 优先 |
| 3 | 二档转售锚点在哪 | Liblib 独苗 → 补 OpenRouter/Cursor 早期 | 转售 = f(毛利, 增速, 生态) |
| 4 | 像不像无问芯穹 | 应用层转售 → **算力/Infra 段单列** | definitions.md §9 |
| 5 | 自持 vs 租赁区别大 | 不分轻重 → 重资产 6-12x / 轻资产 15-25x | §9 资产轻重分档 |
| 6 | 国内有对标吗 | 海外锚 → 优刻得 7.57x/并行 4.45x 国内中位 7.5x | §9 国内对标表 |

**套路要点**：校准模式：复核方每次提问都在补维度——先承认类别/维度缺失，再拉数据补齐，最后把规则写进 definitions/comps-source。

## 5. 防止「锚是拍出来的」自查清单

- [ ] 这个倍数有几个独立锚点支撑？（≥2 才算稳，1 个标 ⚠️）
- [ ] 锚点是不是次新股？（上市 <12 个月不可作锚，只作反例）
- [ ] 锚点口径是 TTM 还是 forward？（一级市场 ARR = forward；二级 TTM——混用要标注）
- [ ] 国内/海外该给哪个？（国内折价 30-50%）
- [ ] 有无战略收购溢价/单源/未验证轮次？（标 ⚠️）
- [ ] 有无反例？（反面教材放锚带另一端）
