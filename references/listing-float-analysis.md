# 次新股低流通盘炒作识别（四表法）· v1.6 框架洞察沉淀

> 来源：2026-08-28 框架洞察「大概率是低流通盘炒作短期高峰估值」——对 18 家港股 AI 应用/SaaS 分析时实证坐实。
> 适用范围：任何次新股（上市 <12 个月）估值报告必附；老股（充分解禁）不附但需确认解禁状态。

## 核心逻辑

次新股市场估值 = 基本面估值 + **流通盘稀缺溢价**（低流通盘 + 稀缺叙事 + 打新情绪）。这个溢价不是基本面均衡价，**解禁前透支、解禁后抛压**。判断一家「AI 第一股」的高 PS 是否被低流通盘推高，用四表法。

## 四表明细

### 表 A：Pre-IPO 融资史
| 字段 | 数据源 | 备注 |
|---|---|---|
| 轮次/时间/金额/投后估值/投资方 | 招股书「歷史、發展及公司架構」章节（S 级）+ 投资界 vc.pedaily.cn / 36氪 pitchhub 融资库（B 级交叉） | **关键信号：一级市场估值停滞**（如极视角 C3 轮 23 亿 2022-10 → D 轮 23.1 亿 2024-11，两年零增长）——一级市场早已定价，二级市场却炒高 |
| 股东结构 | 招股书股权章节 | 看一致行动人占比、有无控股股东、Pre-IPO 机构名单（君联/高瓴/IDG 等） |

### 表 B：发行结构
| 字段 | 计算/数据源 |
|---|---|
| 发行价 / 发行市值 | 招股书封面 + 配发结果公告（S 级） |
| 发行股份 / 总股本 | Wind 总股本 + 招股书发行股数 |
| 发行占比 | 发行股份 ÷ 总股本（极视角 11.1% / 海致 6.9% / 滴普 7.6%） |
| 基石投资者 | 招股书「基石投資者」章节（S 级）——基石锁定通常 6 个月 |
| **真实自由流通** | （发行股份 − 基石锁定股份）÷ 总股本——极视角 10.0% / 海致 5.9% / 滴普 7.6% |

### 表 D：换手与情绪
| 字段 | 计算 |
|---|---|
| 市值 ÷ 最近一轮 Pre-IPO 估值 | 当前市值（港元×0.92≈人民币）÷ Pre-IPO 投后估值 |
| 当日换手率（对自由流通） | 当日成交量 ÷ 真实自由流通股（Wind 成交量字段） |
| 流通盘市值 | 当前市值 × 真实自由流通占比 |

## 判定标准（写死）

**市值 ÷ Pre-IPO 估值 >3 倍 且 真实自由流通 <10% = 低流通盘短期泡沫结构**（解禁前透支，解禁后有抛压风险）。

实证（注：迅策已 2026-08 前充分解禁、海致控股股东已解禁但基石未全解——下表为上市初期锁死期观测值，作「解禁前 vs 解禁后」对照）：
- 极视角：3.9 倍 / 流通 10.0% / 换手 0.92% → ✅ 泡沫（筹码锁死，2026-09-30 基石解禁观察窗）
- 海致：5.8 倍 / 流通 5.9% / 换手 6.44% → ✅ 最极端（~12 亿港元流通盘撑 207 亿市值）——⚠️ 控股股东 2026-08-13 已解禁（普通主板 8.05(3) Rule 10.07 6 个月），解禁后高波动（单日 ±20%）含控股股东抛压释放；但基石 JINGSHENG/JSC 未到（2026-11 / 2027-01），锚点资格待基石全解后重估
- 滴普：1.5 倍 / 流通 7.6% / 换手 28.47% → ⚠️ 低流通盘但炒作已退潮（上市 10 个月，年内 -50%，换手充分）——**天然对照实验：证明低流通盘溢价会退潮**（控股股东 2026-10-28 解禁观察窗）

## 锚点纪律联动（v1.6.1 + v1.13.6 修正）

次新股市场 PS（25-35x）**不可作估值锚**——含流通盘稀缺溢价，不是该档位合理倍数。只能作「偏离分析」的反例锚（说明市场如何被扭曲）。
**⚠️ 判定锚点资格按「解禁状态」不按「上市时长」（v1.13.6 聚水潭/海致/迅策教训）**：
- **普通主板**（盈利/8.05(3)）控股股东 6 个月解禁 → 上市满 6 个月 + 抛压消化后**可作锚**（聚水潭 2026-04 解禁、框架校准方 2026-09 裁决好锚点；迅策 2026-06 解禁后可作锚）
- **⚠️ 基石分批锁定期特例（v1.15.1 海致实证）**：锚点判定以**控股股东**锁定窗口为准，但若基石锁定期 >6 个月未全解，**「已充分解禁」不成立**，锚点资格待基石全解后重估（海致 02706：控股股东 2026-08-13 已解禁，但 JINGSHENG 基石 2026-11-13 / JSC 基石 2027-01-13 未到——2026-09 时点不可作锚）
- **18C 特专科技**控股股东 12 个月 → 上市满 12 个月才可评估锚点资格（极视角 2027-03 / 滴普 2026-10 前不可作锚；滴普无基石，控股股东 2026-10-28 为唯一观察窗）
- 未解禁次新一律只作反例（群核 2026-10-17 前 / 科拓 2026-12-26 前）
- 锚点明细表（附录 B）只取充分解禁标的（范式智能 2023-09 / 金蝶 / 中软 / 埃森哲 / 聚水潭 2026-04 ✅）或一级市场非上市标的。

## 工具链

- Wind 拉总股本/成交量/市值（get_stock_price_indicators，注意「流通股本」「自由流通股本」指标港股无效——用招股书发行结构算）
- 招股书 PDF 下载：`curl -sL -o prospectus.pdf "<hkexnews URL>"`，pymupdf 全文检索（禁售/基石/包销/权益变动表关键词）
- 配发结果公告（hkexnews 编号 _c.pdf）含最终发行结构/基石实际认购

### 招股书核实实操（2026-09-02 海致/迅策实录——判定上市章节/解禁的完整路径）

**① 找招股书 PDF 直链（按效率排序）**：
1. exa/web_search 搜「公司名 + hkexnews + 招股章程 + filetype:pdf」——通常直接命中 hkexnews 原始 URL（迅策 `listedco/listconews/sehk/2025/1218/..._c.pdf` 即此法找到）
2. 雪球镜像 `stockn.xueqiu.com/<代码>/<文件号>.pdf`（从搜索摘要可得）——⚠️ 注意可能只是配售结果公告（10 页）而非招股书全文，下载后先看页数（招股书通常 500-650 页）
3. hkexnews titleSearchServlet.do API：中文 title 搜**搜不到上市公司自己的招股书**（只返回基石投资方公告，迅策只搜到中视金桥）——需浏览器走公司下拉选择或已知 stockId，成本高，优先 1/2
- **⚠️ 下错文件陷阱**：配售结果公告 = 10 页 PDF（含最终发行价/配售结果/股本结构，有用但无上市依据段）；招股书全文 = 500+ 页（含「申請於聯交所上市」段）。别把公告当招股书。

**② 判定上市章节（海致/迅策修正法）**：
- 检索位置：招股书「概要」章节的「**申請於聯交所上市**」段（海致第 29 页 / 迅策第 19 页，约 PDF 前 40 页内）——不是全文 grep「18C」（海致/迅策全文 0 处 18C，但 8.05(3) 就在概要段）
- 检索词：`8.05(3)` / `市值╱收益` / `市值╱收入`——命中即普通主板市值/收入测试 → **控股股东 6 个月**
- 全文 grep「18C」「特專科技」0 命中 = 非 18C 的强信号（18C 招股书必在概要段明写「特專科技公司…根據上市規則第18C章」，如智谱 2513 招股书原文）
- HKEX 官方 18C 名单权威对照：hkexgroup.com → 观点文章「解讀特專科技上市章節」(18c-explained)——截至 2026-03 共 14 家（晶泰/黑芝麻/越疆/云迹/滴普/文远/希迪/五一视界/壁仞/智谱/MiniMax/华沿/极视角/傅里叶），海致/迅策不在列 = 铁证非 18C

**③ pymupdf 检索模板**：

import fitz
doc = fitz.open('prospectus.pdf')
for pat in ['8.05(3)', '18C', '特專科技', '申請於聯交所上市']:
    hits = [i for i in range(len(doc)) if pat in doc[i].get_text()]
    print(pat, hits[:8])
