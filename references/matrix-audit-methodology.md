**锚点纪律补充（v1.9.0 后**框架校准记录**：团队确认）**：
- **收购价 ≠ 公允倍数**：Cursor $60B 是 SpaceX 全股票收购价（含控制权溢价，SpaceX 买数据喂 Grok+人才），独立估值 Series D 才 $29.3B——主锚用 15x total 并标注「收购价含战略溢价」，与 OpenRouter 同例。市占下滑（41%→26%）的减速领导者，收购价更不反映公允倍数。
- **过渡态档位合并哲学**：档位之间边界模糊（转售↔自研↔收租都是过渡态）时，优先合并成一个档 + 档内判据插值，不硬分子档——判据要可操作（三判据：数据飞轮闭环 / 高切换成本 / 收入单位）。

## 一、逐格三分法

| 判定 | 标准 | 处置 |
|---|---|---|
| ✅ 硬锚 | 真实交易价（一级融资/收购价/充分解禁上市公司 PS）+ 多源或官方一手 | 区间围绕锚点，可参与跨档比较 |
| ⚠️ 外推 | 无直接锚但逻辑成立（从相邻格平移/增速内插） | 显式标注「推断」，取区间下沿，不参与跨档比较 |
| 🕳️ 空格 | 无样本（如 tier0 g4 项目制>60%增速、tier3 g1 收智慧租低增速） | 留空防瞎编——**宁可空着也不填数字** |
| 🔴 存疑 | 锚点单源 C 级 / 战略收购价冒充公允价 / 脚本与文档不一致 | 必须修：降级标注或同步脚本 |

## 二、硬锚来源优先级（comps-source.md 已收录）

1. **充分解禁上市公司**（上市 >12 个月）：范式智能 1.87x（2023-09 上市）/ 金蝶 / 中软——PS 是市场均衡价
2. **一级市场融资价**：Harvey 44-52x / Perplexity 40-51x / Replit 17.1x / Lovable 26.6x / Suno 18x——有轮次有估值
3. **收购价**：Cursor $60B / Liblib $2-3B / OpenRouter $7.5B——注意收购含战略溢价
4. **官方一手**：ElevenLabs 官方博客披露 ARR/估值

**次新股（上市 <12 个月）不可作锚**——滴普 25.3x 是低流通盘+叙事溢价，只作反例锚。

## 三、首轮审计发现的问题类型（未来审计照此排查）

1. **脚本-文档漂移**（最严重）：estimate.py `tier1 g4 = (30,50)` 但 SKILL.md/definitions 已废弃 30-50x（v1.7.10 **框架校准记录**：团队纠正）——**文档改了脚本没同步，跑出来高估一档高增速公司**。审计必须对比 estimate.py MATRIX vs SKILL.md 矩阵表 vs definitions §10 三处一致性
2. **上沿靠战略收购价**：tier2c g4 的 55x 靠 OpenRouter 53.6x/Cursor 早期 100x——是「叙事上限」不是公允价，应分层标注（17-35x 公允 / 35-55x 战略溢价）
3. **单源锚**：Writesonic（C 级）/ Copy.ai（C 级）/ Legora（C 级单源 🔴）——单源标「单源待验证」，不参与主带
4. **锚点归类错误**：Glean 89% 增速是 g4 却放进 g3 格子——检查增速是否匹配增速档
5. **区间上沿无支撑**：tier0s g3 上沿 4.0x 但唯一硬锚范式只有 1.87x——上沿应能被锚点覆盖或收窄
