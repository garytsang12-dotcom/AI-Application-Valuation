## 三、商业模式定档（收入单位与估值档位）

> 核心问题：这家公司的收入单位是什么——项目 / 席位 / Token / 结果？收入单位决定档位，档位决定估值天花板。

**🔴 收入单位实证（定档三查——v1.14.0 框架硬性要求，必须读财报原文填数字，禁止留空/只写「需 DD」）**：
1. **收入确认时间分类**（财报「收入确认」附注，[N] 页码）：按**时间点确认**（验收/交付制）占比 ___% ｜ 按**随时间推移确认**（订阅/持续）占比 ___% → 判定：时间点 >70% = 项目制坐实；随时间 >50% = 订阅可上一档
2. **分部拆分**：自称的新业务/平台（Token/SaaS/智能体等）实际占比 ___%（财报原文，非管理层指引）——<15% 只作爬升检验期权不给独立档位
3. **管理层自我表述**：是否称「探索中/推进中/早期」→ 是则按当期结构估值（自称商业模式 ≠ 会计确认结构）

## 五、财务核查与质量评分

> 同样一笔推理支出，一家是烧掉的费用，一家是沉淀成认知资产。先扫账本（在不在资产化），再评质量（资产化得好不好）。

**账本定性**：推理支出是费用还是投资？
- 费用型：模型升级/涨价跟着变、客户用完就走、数据沉淀不下来 → 烧掉了
- 资产型：调用越多自有模型越强、客户越难离开 → 在攒资产

**账本三核查（纯财务视角，判断刻度）**：

| 核查项 | 判断刻度 | 标的实测 | 数据状态 |
|-------|------|------|------|
| IER（推理成本÷收入） | 健康 <20% / 警惕 20-33% / 危险 >33%（口径=inference API+自建 GPU 折旧+训练摊销） | | |
| 训练/推理配比 | 推理支出占比在升 = 资产化真信号（在做服务）；纯训练投入 = 还在赌模型 | | |
| 现金流质量 | 经营现金流/亏损幅度趋势：收窄=健康 / 扩大=烧钱加速 | | |

**质量七指标打分（0-10，六档制）**：

| 指标 | 分（语义锚定） | Key evidence（必须填——见第四章对应层结论，不重复论证） | Main risk（必须填） |
|-------|------|------|------|
| 智慧自有率 | 0-10：自研承担核心推理=8+ / 后训练级=6-8 / 微调=4-6 / 无自研纯调第三方=0-3 | ← 第四章①②层 | |
| 单位结果成本趋势 | 0-10：单位成本随规模下降=8+ / 持平=5 / 上升=3-（含人效交叉验证：销售费用率<20% 才算人效真红利） | ← 账本三核查 IER 趋势 | |
| 数据回流 | 0-10：使用数据强制回流且独占=8+ / 回流但可被绕开=5 / 无回流=0-3 | ← 第四章④层 | |
| 归因资产化 | 0-10：推理支出沉淀为可复用资产（eval/数据/模型）=高分；纯烧钱=低分 | ← 第四章④层 + 账本核查 | |
| 护城河层数 | 0-10：六层每层 1-1.5 分（品牌/数据/规模/网络/切换/独占=竞争壁垒，区别于第四章能力六层）；单点=低 | ← 第四章③⑤层 + 客户集中度 | |
| 毛利结构 | 0-10：软件级 70%+ 且毛利额在涨=8+ / 服务级 40-55% 持平=5 / 转售级 <40% 或萎缩=3- | ← 第四章⑥层（结果定价能力） | |
| 爬升检验 | 0-10：收入结构向高档迁移（项目→订阅→用量→结果）=高分；自称但占比<15%=低（嘴爬非真爬） | ← 第二章结构迁移 + 第四章⑥层 | |

> 打分语义定义库：references/definitions.md §6（执行时查表，禁止凭感觉打分）。每格 0/2/4/6/8/10 六档制，禁止出现奇数分——不给「模糊的中间值」留空间。
